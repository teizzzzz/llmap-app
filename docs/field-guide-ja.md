# LLMap 字段説明（日本語）

準拠: **言語景観_採集字段定義表 v6**（2026-07-24）＋ **v6.1 追補**（不明・互补型・B言語入力器の刷新）。
データ契約 SchemaVersion **1.6** / アプリ v1.13.1 時点。

方針は **採集從寬・分析從嚴**。CSV の列名は日本語の正準キーで固定し、選択肢の正準値は
v6 定義表の中文表記（言語名のみ日本語値）をそのまま保存する。画面表示のみ UI 言語
（ja / zh / en）へ翻訳される — データ層は翻訳しない。

複数選択字段の値は「/」区切りで保存する（例: `日本語/英語`）。
値の特殊表記の使い分け:

| 表記 | 意味 |
|---|---|
| `—` | 該当なし（この役割の言語が**無い**、と判断済み） |
| `不明` | 語種**判別不能**（文字はあるが言語を特定できない。具体言語と併記可） |
| 空文字 | **未記入**（まだ判断していない） |

## 名称

表示タイトル用の自由記述。**人力入力のみ**（v6 で AI 対象外）。v6 定義表に無い旧字段
のため Console の研究字段 UI では非表示（列とデータは互換のため保持）。

## B 言語・文字

### 文字性 — `文字 / 記号 / 対象外`

第一軸 = **言語として読める文字を含むか**。

- 駐禁マーク・矢印・トイレ図标のみ → `記号`
- 装飾挿絵・純図形 logo → `対象外`
- 記号＋文字の混在 → `文字`

`記号 / 対象外` を選ぶと B の言語 3 字段は自動で `—` になり入力禁用となる
（無文字は写真級の属性であり、言語字段内の状態ではない）。

### 主要言語 — 複数可・自由追加可

**視覚的に支配的な**言語（code preference）。判定順:
**①視覚面積最大 → ②位置最中心 → ③字号最大**。
三項が等権重なら `日本語/韓国語` のように併記し、無理に一つへ絞らない。

予設: 日本語 / 韓国語 / 中国語 / ベトナム語 / ネパール語 / 英語。
他言語は「＋その他の言語」の検索から追加（正準日本語名で保存。例: `スペイン語`）。
語種を判別できない場合は **`不明`**（v6.1。旧運用「判別不能→その他」は廃止。
具体言語と併記可: `日本語/不明`）。

### 補助言語 — 複数可・無は `—`

次要だが**情報を伝える**言語。
口訣: **それを外すと情報が欠ける → 補助；見栄えだけ → 装飾の言語へ**。

### 装飾の言語 — 複数可・無は `—`

ほぼ情報を伝えず、装飾・ブランド識別・雰囲気のための言語。
欧文の格調的使用・芸術字 logo など。logo がブランド識別のみなら
ここに記し、主要言語には数えない。

### 文字体系 — 複数可（旧字段・AI 対象外）

`漢字 / 平仮名 / 片仮名 / ローマ字 / ハングル(한글) / デーヴァナーガリー /
ビルマ文字 / タイ文字 / ベンガル文字 / アラビア / キリル / その他 / 無`。
人力入力用に保持。Console の研究字段 UI では非表示。

### 多言語関係 — 2 段入力（v6.1）

まず**「是否多语言」**を判断し、単一言語なら `单语型`。
多言語なら Reh (2004) の 4 類から選ぶ:

| 正準値 | Reh 2004 | 判定 |
|---|---|---|
| `单语型` | Monolingual | 単一言語のみ |
| `复制型` | Duplicating | 各言語の内容が**完全同一** |
| `重复型` | Overlapping | 一部重複し、各言語に**独自情報も**ある |
| `部分翻译型` | Fragmentary | 完全情報は一言語のみ、他言語は**断片訳** |
| `互补型` | Complementary | 各言語の内容が**完全に別々**で重複なし（v6.1 新設） |

## C 物質・状態

### 担体類型 — `无媒介 / 产品 / 贴纸 / 旗帜 / 海报 / 宣传册 / 夹心板 / 车辆 / 便签 / 其他`

| 値 | 目安 |
|---|---|
| 无媒介 | 文字が固定位置・物体に直接ある |
| 产品 | 衣服・鞄・新聞など製品そのもの |
| 海报 | 臨時掲示で A4 より大きい紙 |
| 夹心板 | 路上の自立式看板（A 型看板 / gatupratare） |
| 车辆 | 自転車・車・バス・トラック等 |
| 便签 | 簡易レイアウトの臨時貼紙。A4 未満・テープ/画鋲どめ |

### 放置位置 — `建筑物上 / 柱子 / 公告板 / 屏幕 / 道路 / 市政设施设备 / 半可移动物体 / 其他`（v6 新設）

| 値 | 目安 |
|---|---|
| 建筑物上 | 壁・扉・窓 |
| 柱子 | 建物から独立した柱 |
| 屏幕 | 自立式スクリーン（デジタル/アナログ） |
| 道路 | 歩道・広場・駐車場を含む |
| 市政设施设备 | パーキングメーター・郵便ポスト・配電箱等 |
| 半可移动物体 | ゴミ箱・ベンチ・テーブル・足場・工事フェンス・コンテナ等 |
| 其他 | 人など |

### 空間階層 — `低位・接近可能層 / 中位・視線層 / 高位・天際層`（旧字段・AI 対象外）

人力入力用に保持。Console の研究字段 UI では非表示。

### 時間性 — `常设 / 临时·季节性 / 一过性`

判定順: **①明確な失効日付があれば日付に従う → ②固定方式**
（溶接・ボルト → 常设 ／ フック・掛け外し可 → 临时·季节性 ／ テープ・画鋲・易剥離 → 一过性）
**→ ③材質で曖昧なら内容で判断**。
区分線: 撤去したら終わり = 一过性；来季また掛かる = 临时·季节性。

### 可読性 — `完全可读 / 部分可读 / 判读困难`

文字の**物理的明瞭度のみ**を見る（言語が分かるかとは切り離す）。
劣化・褪色・破損 → 部分可读 / 判读困难。
`部分可读` の場合は備考に理由（磨損か字体芸術化か）を必ず書く。

### 重ね書き — `无 / 有（新覆旧） / 有（多层堆叠）`

物理的な叠写・覆盖・修改の痕跡。旧字を新字が覆う、ステッカーの層状堆積 → 有。

## D 社会・機能

### 設置主体 — `行政・公共機関 / 商業・チェーン / 商業・個人店 / 個人 / 団体 / 不明`（旧字段・AI 対象外）

人力入力用に保持。Console の研究字段 UI では非表示。

### ディスコース類型 — Scollon & Scollon (2003)

`规约性话语 / 基础设施话语 / 商业话语 / 交际性话语 / 判读不能 / 其他`。

判定は次の順で当てはめる:

| 順 | 正準値 | Scollon & Scollon | 目安 |
|---|---|---|---|
| ① | `交际性话语` | Transgressive | 涂鸦・未授権貼付・私的メモ（「あるべきでない場所」の話語） |
| ② | `规约性话语` | Regulatory | 行動を規制: 禁止・警告・指示 |
| ③ | `基础设施话语` | Infrastructural | 施設の身元表示: 門牌・路牌・電柱番号・楼層指示 |
| ④ | `商业话语` | Commercial | 販売・広告・招徕 |
| — | `判读不能` | — | 内容が読めない場合の出口 |

### 製作品質 — `专业印刷 / 半专门 / 手作`

**工芸水準のみ**を見る（内容は見ない）。

| 値 | 目安 |
|---|---|
| 专业印刷 | アルミ看板・発光文字・チェーン統一店招 |
| 半专门 | 家庭用プリンタ印刷・通販簡易横断幕・AI 生成ポスター（機械は介在するが専門デザイン/業者なし） |
| 手作 | 手書き・手描き・自作紙 |

### 備考 — 自由記述

この写真からの**新規観察のみ**。接頭辞の約束:

- 分類の迷い・例外・境界判断の理由 → `【判断】…`
- 同一載体上の同款重複数 → `【数量】×N`

## 状態（_status）と審核フロー

| _status | 意味 | DataStatus（自動同期） |
|---|---|---|
| `pending` | 未処理 | raw |
| `ai` | AI 下書き・未校閲 | ai_drafted |
| `human-reviewed` | 人が記入 or 校閲済み | reviewed |
| `final` | 確定（研究利用可） | verified |

Console 専用の審核状態として `needs_review`（要再確認）/ `rejected`（却下）がある。

## AI 起草の対象（13 維度）

文字性・主要言語・補助言語・装飾の言語・多言語関係・担体類型・放置位置・
時間性・可読性・重ね書き・ディスコース類型・製作品質・備考。

AI は下書きのみ: 既存の内容を上書きせず（複数選択は和集合・単一字段は空欄のみ埋める・
備考は追記）、確信が持てない字段は空欄で返す。確定は必ず人の校閲を通す。
**名称・文字体系・空間階層・設置主体は AI 対象外**（人力入力のみ）。
